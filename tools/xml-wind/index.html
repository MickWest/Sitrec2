XML Wind Profile Analyzer

Load an XML weather file. This tool looks for a position (latitude, longitude, elevation) and a vertical wind profile (one element for each altitude, with the wind in it), and proposes the settings that make Sitrec read the file as a wind profile.

The file is read in this browser tab. Nothing is uploaded or sent anywhere.

    Proposed settings

    These lines go in shared.env, or in the env file that the Sitrec container starts with. To try them for yourself only, paste them into Sitrec ▸ Settings ▸ SITREC_ ENV Override. A line marked CHECK is a guess or a default that you must confirm. You can edit the settings here and check them again.

    What Sitrec reads with these settings

    This uses the same reader as Sitrec. The values are converted to feet and knots, and to metres and m/s.

    Other repeating elements in the file

    Report

    A text account of what was found, to send to the person who sets up Sitrec. Without the values it has the structure of the file: tag names, namespace addresses, unit names, counts and kinds of data. It has no measurement, position, time or other text from the file. Read it before you send it: a tag name or a namespace address can itself say where the file comes from.
